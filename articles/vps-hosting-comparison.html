Use Case Analysis

What You're Actually Running

OmniRoute (Docker container): ~600–800 MB RAM idle, bursts to 1.2–1.5 GB under load. Runs on port 20128. Needs Docker available.

Hermes Agent: ~300–500 MB for the backend + session management. Needs Python, tooling, and some disk for session logs.

Overhead: OS (~300 MB), Docker daemon (~150 MB), networking, monitoring. Real minimum: 2 GB RAM, comfortable: 4 GB RAM.

Bottom line: Most $3–$5 VPS plans with 1 GB RAM are too tight. The sweet spot is 2–4 GB RAM, 2 vCPU, ~$5/mo. Hetzner CX22 at €3.79/mo is the price leader for adequate specs. InterServer at $3/mo works if you're budget-strapped and careful about what else runs on the box.

What About Managed Hosting?

There are services that sell managed Hermes Agent hosting (Agent 37 at $3.99/mo, LumaDock at $4.99/mo, etc.). These handle the OS maintenance, updates, and uptime for you.

Trade-off: You get convenience but lose control. You can't easily run additional Docker containers (like OmniRoute) on most managed plans. They're locked to Hermes-only.

For your use case: You need both Hermes and OmniRoute on the same box. Managed hosting that only supports one service doesn't fit. A raw VPS is the better choice.

Recommendation

Go with Hetzner CX22 (€3.79/mo) or CX23 (€5.99/mo)

Best price-to-performance. 4 GB RAM handles OmniRoute + Hermes comfortably. Docker works out of the box. No hidden fees, no reclaim risk. The only downside is EU-only data centers, but latency from the US West Coast is ~120-160ms — fine for API traffic.

If US region is critical: InterServer at $3/mo for the cheapest viable option, or Hostinger at $5.84/mo for the one-click Hermes template ease.
