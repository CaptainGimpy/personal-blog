⚠️ Pain Points & Fixes

Tool call loops / Thought loops

Qwen3.5 gets stuck thinking about using a tool without actually calling it. Common with long context windows — the 9B's attention can't hold schema + history simultaneously.

✓ Fix: Keep context tight. Q4_K_M instead of Q8 leaves more VRAM for KV cache. Set reasonable context limits in Hermes config.

Slows down over multi-turn conversations

As context fills, inference latency increases. By turn 5-8, it's noticeably degraded on a 5060 Ti.

✓ Fix: Use Hermes' context compression (/compress) or set compression thresholds in config.yaml. Cloud fallback for long sessions.

27B+ models over PCIe are unusable

Every single person who tried running a 27B+ model on 16GB VRAM (offloading to system RAM) reported it's too slow to be useful. Massive latency, dropped tool calls.

✓ Fix: Don't. Use cloud for anything that needs 27B+.

Qwen3.5:9b fails after multiple tool calls

"Half the loop failures you're seeing are probably just the 9b not being able to hold schema plus history in attention." — common observation in r/LocalLLM

✓ Fix: This is a 9B limitation, not a setup problem. Plan/execute pattern helps (fresh context for execution).
